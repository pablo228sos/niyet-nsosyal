# NIYET UI Assets Pack

Purpose: visual asset starter pack for the NIYET / NSosyal redesign.

Folders
- backgrounds: full-screen 1920x1080 dark product backgrounds
- gradients: reusable gradient textures
- hero: transparent abstract wave assets
- patterns: transparent grid/dots/lines overlays
- icons: lightweight SVG icon set using currentColor
- brand: NIYET wordmark + mark in SVG
- ui-elements: desktop/mobile composition references
- docs: generated moodboard/reference

Guidance
1. Use assets selectively. Do not put decorative graphics behind dense evidence/data views.
2. Prefer SVG icons over raster icons.
3. Keep motion subtle and respect prefers-reduced-motion.
4. Backgrounds work best on landing/onboarding; dashboards should stay quieter.
5. Treat the moodboard as visual direction, not a literal screenshot to reproduce.
